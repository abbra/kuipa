# Recovery shards

`wordlist.txt` is the SLIP-39 word list (SatoshiLabs, `slips/slip-0039/wordlist.txt`):
1024 common English words, sorted, each identified by its first four letters. It is used
under the Creative Commons Attribution-ShareAlike 4.0 licence of the SLIPs repository
(<https://github.com/satoshilabs/slips>), which allows its use in GPL-3.0 works. kuipa's
shards are not SLIP-39 mnemonics and do not interoperate with its tools; see
`docs/DESIGN-recovery.md` §2.1.
